POURQUOI LES PHOTOS POUVAIENT NE PAS S'AFFICHER ?
--------------------------------------------------
Les 6 photos du ZIP sont valides, ont les bons noms et index.html les appelle correctement.
Le problème apparaît surtout lorsque index.html est ouvert directement à l'intérieur d'un ZIP
ou via certains gestionnaires de fichiers Android : le navigateur reçoit le fichier HTML seul
et n'a pas toujours accès aux autres fichiers du dossier.

SOLUTION 1 — LA PLUS SIMPLE SUR TÉLÉPHONE
------------------------------------------
Ouvre index_standalone.html : les photos sont intégrées dans le fichier lui-même.
Il n'a donc besoin d'aucun autre fichier pour afficher les images.

SOLUTION 2 — VERSION WEB / GITHUB PAGES
----------------------------------------
1. Décompresse entièrement le dossier.
2. Garde index.html et photo1.jpg ... photo6.jpg dans exactement le même dossier.
3. Envoie tous ces fichiers à la racine de ton dépôt GitHub.
4. Active GitHub Pages depuis la branche main et /(root).
